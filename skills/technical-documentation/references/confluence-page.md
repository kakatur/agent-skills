# Confluence Page

Use this format for a new or existing Confluence page, including a local draft
that will later be pasted or published there.

## Reader task

Identify what the page helps readers understand, decide, or operate. Shape the
page around that outcome rather than forcing every page into one template.

Common page types include design explanations, architecture overviews,
decisions, runbooks, onboarding guides, and project status pages. Include only
the sections needed for the selected type.

## Structure and presentation

- Use a specific title that matches the page's scope.
- Open with the purpose, outcome, or current decision readers need.
- Organize headings around reader questions and operational sequence.
- Use tables for compact comparisons, ownership mappings, schemas, or repeated
  fields.
- Put commands and code in code blocks and keep technical identifiers exact.
- Link to canonical repositories, tickets, dashboards, source pages, and related
  decisions instead of copying content that will drift.
- Separate current behavior from proposals, future work, and unresolved
  questions.
- Include dates, owners, status, and decision records only when authoritative
  sources provide them or the user asks to supply them.

Use the target Confluence editor's supported markup when it is known. Otherwise,
produce clean Markdown with headings, lists, tables, links, and code blocks that
can be transferred with minimal reformatting.

## Collaboration boundaries

Preserve existing anchors, links, macros, mentions, task markers, and page
metadata when revising exported Confluence content. Do not claim that a page was
published, reviewed, approved, or communicated unless that action occurred.

## Final check

- Confirm that the opening establishes the page's purpose without a generic
  preamble.
- Verify facts and links against the available sources.
- Confirm that decisions, proposals, risks, and open questions are clearly
  distinguished.
- Remove repeated summaries and sections that do not help the reader act or
  decide.
- Read once for natural flow and once for technical drift.
